{{ st.ocr.detail }}

Para OCR PDF y para leer escaneos en PDF a Markdown.

{% if not st.ocr.ok or 'spa' not in st.ocr.langs %}
  1. Descarga el instalador de Tesseract para Windows desde github.com/UB-Mannheim/tesseract/wiki.
  2. Durante la instalación, en «Additional language data», marca Spanish.
  3. Déjalo en la carpeta por defecto (C:\Program Files\Tesseract-OCR) y reinicia BSOBPDF.
{% endif %}
